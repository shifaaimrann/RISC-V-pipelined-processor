Lab Project for CE/CS 321/330 Computer Architecture - Habib University

->RISCV64 processor on single cycle and pipelined processor with forwarding, hazard unit and flushing implemented.

->Supports R type, I type, S type, SB(beq, bne, blt,bge) instructions.

->Instruction memory for Task 1 and Task 3 contains selection sort algorithm, if it does not sort in simulation, try entering "run 10us" on console to make sure the simulation runs long enough.
